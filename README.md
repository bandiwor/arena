# NULL//ARENA

Арена-шутер с видом сверху: волны врагов, мутаторы арены, апгрейды между волнами, финальный босс МОНОЛИТ.
Strict TypeScript · Vite · Vitest · Three.js · terser · lightningcss. Вся графика и звук процедурные.

```bash
npm i
npm run dev        # http://localhost:5173 (игра), /lab.html (лаборатория ассетов)
npm test           # vitest: детерминизм, реплеи, ИИ, босс, отсутствие роста heap
npm run build      # tsc + vite build (terser, lightningcss, минификация GLSL)
```

Управление: **WASD** — движение, **ЛКМ** — огонь, **колесо / Q E / 1–6** — оружие, **Space / Shift / ПКМ** — рывок, **Esc** — пауза.

## Акты и лор

NULL — карантинный сектор мёртвого архива-ковчега. Хранитель архива, ИИ, перекомпилирует образцы жизни
и испытывает их на арене. Игрок — «Вектор», последний отладочный процесс. Каждый забег — **итерация**,
её номер равен сиду.

- **Акт I «Карантин»** — 9 волн, босс МОНОЛИТ (страж карантина).
- **Переход** (`WavePhase.Transition`, 8 с) идёт в три этапа:
  1. Декомпиляция: скан-волна, колонны распадаются на пиксели.
  2. Перенос: материя со всей арены по спирали стягивается в ядро.
  3. Синтез: ядро взрывается, волна синтеза пишет живую ткань, прорастают наросты, появляются лужи.

  Параллельно печатается терминальный лог архива, игроку восстанавливается 40% здоровья.
- **Акт II «Плоть»** — 4 волны и мини-босс МАТКА. Новые враги:
  - **Червь** — роет, плывёт под полом к упреждённой позиции игрока и прорывается с телеграфом;
    под землёй неуязвим, слышен как 3D-гул;
  - **Паразит** — цепляется к другому врагу: носитель получает −40% урона и +30% скорости;
  - **МАТКА** — неподвижная, плюётся кислотой и рожает рой, червей и паразитов.

  Лужи плоти замедляют игрока, а местные существа движутся по ним свободно.

## Баланс сложности

Правило: высокая сложность ускоряет темп и уплотняет паттерны, а не раздувает HP и урон.
Что растёт с уровнем:
- сколько врагов атакует одновременно («жетоны атаки»);
- насколько короче замахи и телеграфы (`teleMul`, не меньше 0.85);
- точность упреждения, скорость пуль и частота элит.

Правила честности на всех уровнях:
- один удар отнимает не больше 25% HP (на «Сигнале» — 20%);
- после попадания 0.6 с неуязвимости;
- кислота из колец при смерти врага стартует медленно и разгоняется;
- прыжок Роевика и замах Тарана не становятся короче порога реакции;
- после каждой волны восстанавливается часть HP, перед боссом — в 2.5 раза больше;
- щит Призмы ломается под сосредоточенным огнём;
- в «Зеркалах» вражеские пули отражаются только один раз.

Динамическая подстройка асимметрична: если игрок тонет, она помогает до −20%, а если доминирует, давит максимум +8%.

Проверка: `BALANCE=1 BALANCE_OUT=report.txt npx vitest run tests/balance` прогоняет полные кампании без бессмертия
ботами с разной реакцией (83 / 133 / 200 мс и наивный).

| Сложность | 83 мс | 133 мс | 200 мс | наивный |
|---|---|---|---|---|
| Сигнал | 8/8 | 8/8 | 7/8 | 5/8 |
| Шум | 4/8 | 4/8 | 5/8 | 1/8 |
| Помехи | 4/8 | 3/8 | 3/8 | 1/8 |
| NULL | 3/8 | 3/8 | 0/8 | 0/8 |

## Деплой

Каждый пуш в `main` собирает игру (тесты → сборка) и публикует её на GitHub Pages через `.github/workflows/pages.yml`.
Сборка использует относительный `base: './'`, поэтому работает по адресу `https://bandiwor.github.io/arena/`.

## Звук

Весь звук процедурный и синтезируется при старте в двух Web Worker'ах, поэтому главный поток не подлагивает.
Каждый частый звук рендерится в 2–4 вариантах, чтобы повторы не звучали клонами.

**Пространство (для наушников).** Каждый звук позиционируется относительно игрока через HRTF (`PannerNode`).
Вверх по экрану — «впереди», вниз — «сзади». С расстоянием звук тише и глуше (поглощение воздухом).
Арена звучит через процедурную реверберацию: ранние отражения плюс тёмный хвост, разный в левом и правом канале.
В настройках есть переключатель «3D · наушники / колонки» (HRTF или equal-power).

**Живые источники.** До 8 ближайших врагов с «мотором» (дроны, Жала, Гнойники, МОНОЛИТ) звучат постоянным 3D-гулом
с эффектом Доплера и реакцией на заряд атаки. У игрока есть ховер-двигатель, который зависит от скорости,
и сердцебиение, которое нарастает при низком HP.

**Адаптивная музыка.** 5 стерео-стемов (pad, pulse, drive, hype, boss) играют синхронно. Режиссёр (`src/audio/director.ts`)
смешивает их по сглаженному накалу боя, комбо и наличию босса. Громкость нарастает за ~1.6 с, а спадает за ~3.2 с,
так что микс не прыгает. Между волнами и в меню музыка звучит приглушённо, «через стену».

**Атмосфера.** Бесшовные стерео-слои: гул арены, нарастающее напряжение, «порча» босса,
отдельный слой на каждый мутатор (лёд, гравитация, ветер, разгон, зеркала, стазис) и спокойный фон между волнами.

**Состояния:**
- слоу-мо и хитстоп опускают тон новых звуков, приглушают верхние частоты и делают звук более гулким;
- получение урона даёт короткое оглушение, а при сильном ударе — звон в ушах;
- при большом комбо поднимается тон звуков убийств, на пороге ×25 звучит райзер, а при сбросе комбо — «спад».

**Микс без перегрузок:**
- категории (оружие, попадания, враги, мир, UI) идут на отдельные шины;
- при плотной стрельбе громкость каждого звука автоматически снижается, чтобы не было нарастающей «каши»;
- даккинг плавный, на выходе стоят glue-компрессор и лимитер, все параметры меняются через `setTargetAtTime`.

`node tools/audio-check.cjs "?scene=boss3"` — проверка в браузере: пики, скачки громкости, время синтеза,
длинные задачи главного потока, громкости стемов и слоёв (нужен запущенный `npm run dev`).

## PWA

Игра устанавливается как приложение и работает офлайн.

- `sw.js` генерируется при сборке (`pwaPlugin` в `vite.config.ts` + `tools/sw-template.js`): прекэш всех файлов сборки,
  версия = хеш содержимого. Навигация — network-first с откатом на кэш, ассеты — cache-first, шрифты — stale-while-revalidate.
- **Установка:** небольшая плашка в левом нижнем углу, только в главном меню. «✕» прячет её на 14 дней.
  На iOS вместо неё подсказка «Поделиться → На экран Домой».
- **Обновление:** новая версия ставится в фоне и ждёт. Плашка «Доступна новая версия» появляется только в меню,
  на паузе или на экране итогов, во время боя скрыта. «Обновить» переключает версию и перезагружает страницу,
  «Позже» откладывает. Проверка — каждые 30 минут и при возврате на вкладку.
- В dev-режиме воркер не регистрируется (не мешает HMR).
- `npm run check:pwa` — e2e-проверка в Chromium: регистрация, офлайн, плашки установки и обновления, переключение версии.
- `npm run icons` — перерисовать PNG-иконки из `public/icons/icon.svg`.

## Архитектура

```
src/core      rng (sfc32), detmath (детерминированные sin/cos/atan2/exp), spatial grid, event queue, hash
src/sim       World (SoA на typed arrays), Sim.step(cmd), системы, контент (враги, оружие, волны, апгрейды, мутаторы)
src/ai        utility-AI по архетипам, steering, flow field (BFS), токены атак, босс (фазы + паттерны)
src/render    Three.js: инстансинг, GPU-частицы, SDF-квады, пол с декалями, пост-обработка, FX-режиссёр, juice
src/audio     офлайн-DSP: SFX и музыкальные стемы рендерятся в AudioBuffer при старте
src/debug     window.dbg, оверлеи (хитбоксы, ИИ, flow field, сетка, перф)
src/lab       лаборатория: модели, параметры, FX, декали, звуки, пост
```

**Симуляция** работает с фиксированным шагом 60 Гц, без DOM, `Math.random` и системного времени, поэтому одинаково
исполняется в браузере и в vitest. Единственный вход — `InputCmd` на тик (движение, точка прицела в float32, кнопки).
Отсюда реплеи: сид + сложность + записанные команды дают тот же мир бит в бит (проверяется хешем).
Хитстоп и слоу-мо меняют только скорость заполнения аккумулятора, сама симуляция о них не знает.

**Ноль GC в установившемся кадре.** Сущности хранятся как SoA в `Float32Array`/`Uint8Array` с free-list,
события лежат в плоском кольцевом буфере, пространственная сетка пересобирается сортировкой подсчётом.
Рендер записывает данные в заранее выделенные instanced-атрибуты и загружает только изменённые диапазоны.
Тест `zero-GC steady state` гоняет минуту боя на кошмарной сложности с `--expose-gc` и проверяет, что heap не растёт.

**Рендер.** Примерно 15 draw calls на кадр:
- враги: по одному InstancedMesh на тип; анимация частей (ноги, роторы, лепестки, ядро заряда, отдача) считается в вершинном шейдере;
- пули, телеграфы, порталы, лучи и вспышки: один батч SDF-квадов с премультиплицированным блендингом (alpha=0 даёт аддитивное свечение, alpha>0 затемняет, например ядро чёрной дыры);
- частицы без состояния на GPU: CPU пишет только параметры спавна, траекторию с drag и гравитацией (включая падение крови на пол) аналитически считает шейдер;
- пол с гексо-сеткой, рябью от взрывов, завихрениями от гравиколодцев и постоянным слоем декалей (кровь, сок, масло, гарь, медленно выцветают);
- пост-обработка: HDR → dual-Kawase bloom → искажение ударными волнами и линза сингулярности → хроматическая аберрация → AgX-тонмаппинг → глитч (сдвиг блоков, разрывы строк, инверсия) → сканлайны, зерно, виньетка, вспышки урона.

## Стиль и палитра

Неон-нуар: почти чёрная фиолетовая арена, свет дают только игровые объекты. **Цвет означает роль в геймплее**:

| Роль | Цвет |
|---|---|
| Игрок и его снаряды | циан `#2EF2FF` |
| Враги и вражеские снаряды | маджента `#FF2D7A` / `#FF4FD8` |
| Опасность, взрывы | янтарь `#FFA126` |
| Энергия, босс, элита | фиолет `#9B5CFF` |
| Лут, растения | лайм `#B6FF3B` |

Редкость оружия: обычное (циан) → редкое (зелёное) → эпическое (фиолетовое) → легендарное (золото).
Чем выше редкость, тем сильнее отклик: hitstop, хроматика, глитч, вспышка экрана, слоу-мо.

Материалы врагов реагируют по-разному: **плоть** — артериальная кровь, ошмётки и лужи; **растение** — светящийся сок,
листья, лепестки и пыльца; **машина** — искры, масло, дым и гарь; **кристалл** — светящиеся осколки и блёстки;
**пустота (босс)** — глитч-пиксели.

## Враги и ИИ

- **Director** считает напряжение (здоровье игрока, урон за последние ~6 с, плотность врагов) и мягко подстраивает
  сложность в пределах ±12%. Влияет только на количество врагов в волне, точность и кулдауны.
- **Токены атак**: одновременно атакуют максимум N врагов (N зависит от сложности), остальные занимают позиции.
- **Utility AI**: баллы действий видны в оверлее `ai` и в `dbg.inspect(id)`.

| Враг | Материал | Поведение |
|---|---|---|
| Роевик | плоть | окружает по кольцу, извивается, прыжок с телеграфом |
| Дрон-стрелок | машина | держит дистанцию, стрейфит, уклоняется от пуль, очередь с упреждением |
| Таран | плоть | наводится, фиксирует направление, рывок; врезавшись в стену, оглушён |
| Терновник | растение | ищет позицию с линией огня, раскрывает бутон, фиксирует прицел и стреляет шипом |
| Призма | кристалл | прикрывает стрелков, фронтальный щит, медленно поворачивается (её надо обходить с фланга) |
| Гнойник | плоть | медленный мешок с кислотой; рядом с игроком раздувается (зона взрыва на полу) и лопается кольцом кислоты |
| Жало | машина | быстрый дрон-оса: кружит на дистанции, отходит назад и пикирует по зафиксированной линии |
| МОНОЛИТ | пустота | 3 фазы: кольца, спирали, веера, удар с телеграфом, лазеры, призыв помощников, телепорт |

## Мутаторы арены

`src/sim/content/mutators.ts`. Каждый мутатор меняет физику арены (`Phys`) и может иметь свой `tick`:
**РАЗГОН** (скорость снарядов), **КРИОПОЛ** (лёд, инерция), **ГРАВИКОЛОДЦЫ** (блуждающие аттракторы гнут траектории),
**ЗЕРКАЛА** (рикошеты от стен), **ДРЕЙФ** (вращающийся ветер), **СТАЗИС** (вязкие медленные снаряды).
Новый мутатор: добавить объект с `apply(target)` и, при необходимости, `tick`/`exit`, затем указать `mutator: 'key'` в волне.

## Смотреть бота и отладка из меню

- **«Смотреть бота»**: выбираешь мастерство (Новичок / Средний ~200 мс / Опытный ~133 мс / Мастер ~83 мс) и сложность,
  бот проходит полную кампанию. Во время просмотра можно ускорить до 1–8× или **«Взять управление»** — забег продолжишь сам.
- **«Отладка»** (или **F1** в любой момент, в том числе на GitHub Pages) открывает панель:
  - страницы: Лаборатория ассетов, пустая песочница;
  - все сцены;
  - бот играет текущую сцену;
  - время: пауза, шаг, скорость; бессмертие, без ИИ, убить всех, перф-панель;
  - оверлеи; спавн любого врага; выдача оружия; мутаторы; эффекты.

  Модуль отладки подгружается лениво и ничего не стоит в обычной игре.

## Отладка

В dev-режиме (или в проде с `?debug`) доступен объект `window.dbg`; список команд выводит `dbg.help()`.

```js
dbg.scene('shield')                  // готовые сцены: gallery, swarm, archers, gunners, chargers, shield,
                                     //   weapons, boss, boss2, boss3, stress, mutator:<key>,
                                     //   transition, act2, worms, brood, parasites
dbg.spawn('archer', 0, -10, { affix: 2 })
dbg.boss.pattern('laser'); dbg.boss.hp(0.3)
dbg.pause(); dbg.step(10); dbg.timeScale(0.25)
dbg.overlay('ai')                    // hitbox | ai | flow | grid | all     (` переключает)
dbg.inspect(3)                       // состояние, баллы utility, токен, цель
dbg.mutator('gravity'); dbg.weapon('singularity'); dbg.upgrade('multi')
dbg.fx.kill('archer'); dbg.fx.explode(); dbg.post({ bloom: 1.5 })
dbg.replay.save(); dbg.replay.download()
dbg.selfPlay()                       // бот играет сам
```

URL-параметры: `?scene=boss3`, `?wave=6&seed=42&diff=2`, `?god`, `?selfplay`.
Горячие клавиши: `` ` `` — оверлей, F2 — пауза, F3 — шаг, F4 — god.

## Лаборатория (`/lab.html`)

Тот же рендер-пайплайн, что и в игре, плюс орбитальная камера:
- просмотр любой модели; слайдеры процедурных параметров (сохраняются в localStorage, «copy params JSON»);
- состояния анимации (idle, windup, attack, dash, stunned, spawn), заряд, скорость ходьбы, hit-flash, смерть, элитный вариант;
- все FX-пресеты (попадания и смерти по материалам, вспышки выстрелов по каждому оружию, взрывы, сингулярность, рельса, телеграфы, лист декалей), при необходимости в цикле;
- все звуки, предпросмотр пола под мутаторами, настройки пост-обработки.

Для автоматизации есть `window.lab`: `lab.model('archer', { state: 3, charge: 0.7, cam: 'iso' })`, `lab.fx('kill:charger')`,
`lab.set('petals', 9)`, `lab.hideUi()`.
Скриншоты из консоли: `node tools/shot.cjs "?scene=boss2" out.png` и `node tools/labshot.cjs prefix "js@@ms;;js@@ms"`.
